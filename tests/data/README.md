# Independent big-number reference vectors

`reference.tsv` has 496 deterministic cases generated by `generate.go` using
Go's `math/big` package, seed `20260923`. Each tab-separated row records an
operation, binary precision, rounding mode, two exact rational inputs, an exact
rational result, and the floating-point inexact flag. The first 256 rows use
`big.Rat` addition, subtraction, multiplication, and division on integers well
beyond 64 bits. The remaining 240 rows use `big.Float` at 3, 7, 16, 53, or 113
binary bits and all six corresponding rounding modes. Binary operands are
rounded before arithmetic, matching the consumer API; outputs are converted
back to exact rationals for comparison. Go `big.Float.Sqrt` does not define its
accuracy flag, so the generator computes square-root exactness by squaring the
exact output rational and comparing it with the exact rounded input rational.

The generator uses only Go's standard `math/big` and `math/rand` packages. It
does not import the GoML implementation or derive expectations from it. Run
`go run generate.go > reference.tsv` here to regenerate, then review the
diff. SHA-256 of the checked-in vector file:
`8fb7bb0979475a46ae9ec3596ef41b8bb9a0f5dfca75de87e25f709f38bbd860`.
